# Medusa DTC Next.js storefront

Next.js 15 DTC storefront for [zerops-recipe-apps/medusa-dtc](https://github.com/zerops-recipe-apps/medusa-dtc). Deploy with `zeropsSetup: dev` or `prod` from [`zeropsio/recipes/medusa-dtc`](https://github.com/zeropsio/recipes/tree/main/medusa-dtc).

Local: `yarn dev` on port 8000 against your Medusa `API_URL` and publishable key.
