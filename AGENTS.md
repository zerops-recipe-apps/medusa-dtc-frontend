# medusa-dtc-nextstore

Next.js 15 DTC storefront (Yarn 3 Berry). Pairs with [medusa-dtc](https://github.com/zerops-recipe-apps/medusa-dtc).

- Zerops setups: `dev` (`deployFiles: ./`) and `prod`
- Port `8000`, readiness `/api/health`
- Project vault: `APP_URL`, `API_URL`, `CHANNEL_PUBLISHABLE_KEY`, `MEDUSA_HOST`, `RELOAD_SECRET`
